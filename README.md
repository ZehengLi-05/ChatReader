# ChatReader

![ChatReader 图标](assets/chatreader.png)

ChatReader 是一款 Windows 微信群聊阅读助手，将本机群聊文字整理成重点、待办和待确认事项，帮助你快速跟上讨论。

聊天读取和模型分析在本机完成，软件不会向联系人或群发送消息。

## 功能

- **群聊摘要**：按群和时间范围整理讨论，查看重点与安排变化。
- **待办整理**：提取任务、负责人和截止时间，保存自己的处理状态。
- **原文核对**：查看摘要引用及上下文，核对结论来源。
- **增量阅读**：处理上次成功总结之后的新发现记录，包括后补或修订的消息。
- **本地管理**：选择本地模型，管理账号、关注偏好、历史摘要和缓存。
- **启动与更新**：每次打开检查新版本，由你选择重启更新时间；可按需开启开机启动，默认关闭。

当前分析范围为文字，图片、语音等内容仅保留占位。
